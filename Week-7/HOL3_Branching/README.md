# HOL3 - Git Branching

## Objective
Learn how to create and switch between Git branches.

## Commands Used

```bash
git init
git branch feature
git checkout feature
git add .
git commit -m "Added feature.txt"
git checkout main
```

## Result

- Created a new branch named `feature`.
- Added `feature.txt` in the feature branch.
- Switched back to the main branch successfully.
