# HOL2 - Git Ignore

## Objective
Learn how to use the `.gitignore` file to prevent unnecessary files from being tracked by Git.

## Files

- app.java
- notes.txt
- .gitignore

## .gitignore Content

```gitignore
*.class
```

## Git Commands Used

```bash
git init
git status
git add .
git commit -m "HOL2 - Git Ignore"
```

## Result

- The `test.class` file is ignored by Git.
- Only the required source files are tracked.
